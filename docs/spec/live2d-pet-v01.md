# Spec: CC GUI Live2D Pets v1

## 1. 挂载与生命周期

- 插件注册一个 `ui:overlay` 常驻视口内容和一个 `ui:settings-section` 设置页。
- Overlay 宿主为固定、空白区域 pointer-transparent 的视口；桌宠画布和控件自行启用 pointer events。
- 插件激活时创建一个 `PetRuntime`，注册会话和运行时 hook；卸载时撤销注册、销毁 PIXI、取消 DOM 监听、计时器、rAF 和订阅。
- 运行时 vendor 脚本通过 `ctx.assets.bundleUrl()` 加载。插件不使用远程 `<script>`。
- PixiJS 6.5.10 加载后先加载同版本官方 `@pixi/unsafe-eval` 适配模块，再初始化 Live2D；以解释执行的 uniform 同步替代动态代码生成，不放宽宿主 CSP。
- 位置、配置和状态订阅在异步资源加载前建立；vendor 或模型加载失败后继续生效。初次加载和后续模型切换使用同一串行队列。
- 卸载释放已挂载模型的 Cubism core；模型已创建 core 后发生加载失败也要释放实例。卸载后才成功或失败的加载在结果到达时按初始化阶段回收，迟到的失败不再创建降级 DOM。
- 宿主 SDK 最低为 `0.3.12`（共通兼容线重新编号，承载 CCB + Live2D 通用能力）；manifest 使用 `>=0.3.12`，允许 `0.3.16` 及后续更高版本通过握手，拒绝低于最低版本的宿主。宿主仍须提供插件使用的通用接口和权限，不要求与插件镜像的版本戳精确同版。

## 2. 设置与持久化

设置页包含：

- 显示开关，默认开启。
- 「窗口非激活时保持动态」开关，默认关闭：开启后失焦/隐藏不再暂停渲染循环。
- 尺寸滑杆，40–400px，默认 160px。
- 渲染帧率 30、60、不限制，默认 30；即时作用于 PIXI ticker。
- 人设下拉：六个内置人设和 JSONC 文件中的自定义人设；触发器、圆角弹层和选中态沿用宿主菜单视觉，并支持点击外部或 Escape 关闭与方向键导航。
- 模型列表：五个内置只读模型和用户自定义模型。
- 开发者选项总开关；开启后显示状态调试面板和点击分区叠加开关。

标量设置和位置通过 `ctx.storage` 持久化。人设和自定义模型通过 `ctx.documentStorage` 的 `personas.jsonc` 与 `custom-models.jsonc` 持久化；写入使用 CAS，冲突时重读后重试一次。首次读取人设文件会落地带注释的模板，之后插件不覆盖用户内容。

命令面板中的「重置桌宠位置」把可见位置和持久化坐标同步为 `right: 24px`、`bottom: 20px`，不修改尺寸配置。加载中或静态爪印降级时，位置与显示开关仍可即时更新。
- 模型画布右键只显示「刷新宠物」和「关闭宠物」；刷新串行重载当前模型并保留位置/尺寸，关闭持久化显示开关为关闭。

自定义模型支持：

- 远程 `http(s)` `.model3.json` URL；URL 的 host 必须命中 manifest 的精确 `network:<host>` grant。
- 本地模型目录：用户通过资产目录选择器授权目录，再填写目录内相对 `.model3.json` 路径；所有纹理、moc3 和其它兄弟资源都从该 grant 加载。
- 空间分区覆盖字段 `spatialTap`，值为 0–1；空字段继承默认值。
- 动画映射 `animationMap`，每个状态和互动部位可以选择多个动作组，触发时随机选择。

模型来源编辑规则：

- 手动修改模型地址会清除该草稿的旧目录关联。改填远程 URL 后，动作预览与保存都经过 `assets.remoteUrl` 的权限检查；保存的远程条目不携带 `directoryGrantId` / `directoryPath`。
- 手动改写本地目录文字不代表重新授权，需通过目录选择器重新选择；只修改名称、分区或动画映射时保留原目录来源。
- 目录选择结果仅更新发起请求且仍有效的草稿。改地址、开始新一次目录选择、添加/保存、取消或切换编辑对象、卸载设置页后，旧请求的成功和失败回调不再改写界面。
- 当前目录选择失败或取消时保留已有草稿。切换草稿来源不撤销宿主持久化的目录 grant，避免影响使用同一目录的其它模型。

## 3. 状态镜像

运行时事件映射：

| 宿主信号 | 桌宠状态 |
| --- | --- |
| `onTurnStarted` | `thinking` |
| `permission-requested` | `waiting` |
| `turn-failed` | `error` |
| `assistant-completed` 或 `afterTurn(completed)` | `done` |
| `turn-cancelled`、运行时退出或当前跟踪会话关闭 | `idle` |
| 无跟踪回合时创建会话，或恢复另一会话 | `idle` |
| 首轮开始后返回当前会话 ID，或恢复同一跟踪会话 | 保持当前状态 |

桌宠只表现**当前激活会话**的回合：激活会话由宿主话题 `session://activated`（切标签页、切会话、新建会话都会发射）
更新，宿主未报告激活会话时跟随最近一次 `onTurnStarted`。切到别的会话只改变「表现哪一个会话」，
被切走的回合继续在后台跟踪（含终态），切回来立即恢复该会话的当前状态；后台会话的回合只记录，不驱动表现。

每个会话独立跟踪自己的回合，不设数量上限：回合到达终态（取消/完成保持结束/运行时退出）或会话关闭时才释放，
所以切到任何会话都能立刻恢复它的实时状态。只有已通过 `onTurnStarted` 跟踪的 `turnId`
能驱动该会话的状态，没有跟踪回合时忽略这些回调，避免关闭、取消、失败或完成保持期结束后的迟到事件重新激活桌宠。
完成状态保持 3.5 秒后回到 idle 并释放该会话的回合；新的 thinking、waiting 或 error 会立即取消保持计时。

宿主可能先开始首轮、后返回 native session ID。此时同引擎、同工作区的创建事件只补齐会话身份，不中断思考/等待/完成表现。会话关闭与恢复按引擎、session ID、工作区路径匹配：关闭其它会话不干扰当前回合，恢复另一会话会作废旧回合的事件。

表现保持原插件规则：

- idle、error、done 使用约 2.5 秒的瞬态气泡。
- thinking 阶段在 0、15、40 秒切换台词和状态动作，气泡常驻。
- waiting 阶段在 0、30、90 秒切换台词和状态动作，气泡常驻。
- 台词按当前人设的 13 个池解析；自定义人设沿 base 链覆盖池，未覆盖池继承基座，最终回退傲娇。

## 4. 互动与渲染

- 命名 HitArea 按头、腿、手、身体优先级归类；空命中或只有未识别命中时按模型包围盒五矩形回退。
- 单击/拖动阈值为 6px。超过阈值进入拖动，拖动期间隐藏气泡且不触发互动；松手后以 right/bottom 保存位置。
- 拖动中的本地坐标不受会话状态等无关快照覆盖，松手保存实际最终位置。
- 模型切换会终止旧画布的拖动状态，后续位置重置与新画布交互不沿用旧拖动起点。
- 有效点击只做 80ms 防抖，不等待气泡或动作结束；同一台词池随机避开上一条。
- 互动和非 idle 状态动作使用 FORCE 优先级，idle 使用 IDLE；重新播放前停止旧 motion。动作结束由 `motionFinish` 恢复当前状态动作和鼠标跟随。
- 尺寸语义为「可见宽度」：缩放基准取出现前实测的绘制区域，**预热结束后冻结**；
  之后动作把覆盖范围撑大时只记录覆盖范围，不在运行中重设画布、缩放或模型位置，避免尺寸调整完成后继续抽动；
  下一次明确尺寸变更或「刷新宠物」时统一应用最新覆盖范围。测量失败时回退为按模型盒宽高比。
- 设置页尺寸滑杆采用 120ms 尾部合并：连续拖动只提交最后一档，松手后不会继续排队应用旧尺寸。
- 尺寸变更通过 rAF 合并，同一帧多次调整以最后一次为准，包括改回已绘制尺寸。
- 画布重设会清空位图，因此每次明确尺寸变更都在同一帧内立刻重绘，拖动尺寸不出现空白帧。
- 桌宠整只可见：渲染尺寸受视口限制（宽度 ≤ 视口宽 − 16，画布高 ≤ 视口高 − 16），
  高瘦模型在大尺寸下自动缩小；窗口缩放后重新适配。
- 出现即定形：画布先隐藏并累积绘制区域样本（10 个稳定样本，最多 40 帧），定形后才显示，
  避免桌宠出现后再改尺寸。
- 绘制区域采样在预热后以每 30 帧一次的看门狗继续（读渲染后的帧缓冲），取**并集**而不是首帧一锤定音；
  采样结果只供下一次明确适配使用，不触发布局变更。
- 采样包围盒贴到画布边缘说明被画布截断，该侧外扩 12px，避免下一次适配继续裁切。
- 桌宠钉在画布右/下边（画布在视口中右/下锚定）；明确尺寸变更或刷新时重新适配，运行中模型视觉位置不被迟到姿势改写。
- 桌宠可贴右/下边；拖动位置钳制在视口内（`right ≤ 视口宽 − 桌宠宽`、`bottom ≤ 视口高 − 桌宠高`），
  窗口缩放后同样重新钳制，桌宠不会被拖出或留在画面外。
- 指针命中按像素判定：渲染后读指针附近一小块帧缓冲，透明处把画布切成 `pointer-events: none`，
  点击/滚轮落到下方宿主组件；有像素处恢复拦截，桌宠仍可点击、拖动。拖动期间不切换拦截状态。
- 鼠标在页面内移动时调用模型 focus；拖动、隐藏、失焦和非 idle 动作期间抑制 focus，离开页面后复位。
- 默认在 `document.visibilityState` 非 visible、窗口 blur 或显示开关关闭时暂停 Application ticker 和当前模型的自动更新，恢复时继续；不停止其它消费者共用的全局 ticker。开启「窗口非激活时保持动态」后，失焦/隐藏不再暂停，仅显示开关仍生效。
- 自定义模型条目若指向 Cubism 2 资产（`.model.json`），设置页明确标注不受支持；模型加载失败写入控制台告警（含 URL 与原因）而不是静默降级。
- 新建 PIXI 实例立即应用当前启停状态，无需等待模型网络请求结束；模型切换不得丢失尚未绘制的尺寸配置。
- WebGL、vendor 或模型加载失败时销毁渲染层并显示静态爪印。

## 5. 验收

- 安装/卸载无残留。
- 默认 Hiyori 可通过已声明的 jsDelivr grant 加载；五条内置清单可切换并显示许可链接。
- 自定义远程模型和授权目录模型能加载 `.model3.json` 及相邻资源；未授权远程域名在设置中明确提示。
- 设置重载后配置、位置、人设和模型列表保持。
- 真实 CC GUI turn hook 能驱动全部五态，长思考/审批阶段按时间推进。
- 点击、拖动、鼠标跟随、完成庆祝、隐藏和失焦暂停均不影响宿主输入。
- `bun run validate` 通过：类型检查、单元测试、bundle 构建、manifest/产物/黑名单校验。

## 6. 平台边界

移植版不保留 DSH 的 `ctx.webServer`、JSON API、SSE、`file://` 绝对路径路由或 `cordis.patch.yml`。这些能力由 CC GUI SDK 的 hook、storage、documentStorage、assets 和 overlay 扩展点替代。
「当前激活会话」只能通过宿主话题 `session://activated`（需要 `events` 权限）获得，SDK 没有其它等价信号。
