# Intent: CC GUI Live2D 桌宠插件

## 目标

把 `dsh-live2d-pets` 的用户可感知能力移植为 CC GUI JS 插件：桌宠常驻于 CC GUI 视口，反映当前 AI 会话状态，同时提供互动陪伴和可持久化设置。

## 用户价值

- 长任务执行期间提供明确的状态反馈：思考、审批等待、错误和完成。
- 不遮挡宿主核心 UI；默认小尺寸、右下角、可隐藏、可拖动。
- 不要求用户把模型文件复制进插件；用户可使用策展 URL 或明确授权的本地模型目录。
- 通过人设台词、分部位互动和鼠标跟随提供陪伴感。

## 成功标准

1. CC GUI 可从 `dist/` 安装并加载插件，卸载时没有残留 overlay、hook 或计时器。
2. 状态事件驱动桌宠状态，思考/审批的阶段气泡、错误/完成反馈和完成保持期与原插件一致。
3. 头、腿、手、身体互动、拖动、鼠标跟随、动作优先级和页面失焦暂停均可用。
4. 设置页可修改显示开关、尺寸、帧率、人设、模型、开发者选项，并在重载后保持。
5. 六种内置人设、自定义 JSONC 人设、五条内置模型清单、自定义模型、空间分区覆盖和动画映射均可用。
6. WebGL 或模型加载失败时降级为静态爪印，不影响宿主。

## 平台约束

- 只有 CC GUI PluginContext 能力：不得调用 Tauri IPC、任意文件 API 或 CC GUI 内部模块。
- 运行时状态使用 `session.lifecycle.read` 与 `runtime.events.read` hook，不复制 DSH Host/SSE 路由。
- 标量配置使用插件 KV；人设和自定义模型使用插件私有 `documentStorage`。
- bundle 资源使用 `assets:bundle`；本地模型使用 `assets:directory` 用户授权；远程 URL 受精确 `network:<host>` 权限限制。
- 模型文件不随包分发，Live2D 运行时脚本作为固定版本 bundle 资源随包分发。

## 明确不做

- 脱离 CC GUI 的独立桌面窗口、系统托盘宠物或后台守护进程。
- 任意远程域名的运行时权限申请；未在 manifest 声明的远程模型域名必须更新插件权限后才能使用。
- 音效、喂养、养成、模型市场和完整通用 Live2D 编辑器。
